# Первый запуск WESP

Первая alpha для Linux/KDE Plasma6: музыка с выхода компьютера, подсветка по
акценту/обоям и системные сигналы. Можно попробовать без ESP. Для устройства
нужен один выбранный контроллер: WESP по USB/Wi-Fi либо существующий WLED по USB.
Автор Chapman, лицензия MIT. [Проверенное окружение и ограничения](FIRST_ALPHA.md).

## Установить и попробовать

Распакуйте релизный архив и откройте терминал в папке `wesp`.
Python-зависимости служб перечислены в `requirements.txt`; системные GI/DBus,
Plasma и аудиопрограммы — в README. Для отдельного окна нужен PySide6:

```sh
python3 -m venv --system-site-packages "${XDG_DATA_HOME:-$HOME/.local/share}/wled-control-tools/desktop-qt6"
"${XDG_DATA_HOME:-$HOME/.local/share}/wled-control-tools/desktop-qt6/bin/python" -m pip install -r requirements-gui.txt
/usr/bin/python3 manage.py doctor
/usr/bin/python3 manage.py install
```

Запускайте от обычного пользователя. Если doctor называет недостающий пакет,
установите его средствами своего дистрибутива и повторите проверку.
Откройте **WESP** из меню приложений или командой `wesp`. Выберите
**«Попробовать без ESP»** и включите музыку: настройки демо не меняют настоящую
ленту. «Шкала»/«Пульс» и готовые варианты доступны на странице «Музыка».
Язык берётся из сеанса; доступны русский и английский. Виджет Plasma —
необязательный быстрый пульт. Закрытие окна оставляет службы работать.

## Новая ESP: прошивка и первый свет

1. Подключите поддерживаемую ESP32 по USB. В **«Подключение» → «Настроить новую
   ESP»** нажмите «Найти», выберите нужный порт и **«Подготовить прошивку WESP»**.
   Релиз с native firmware уже содержит проверенные файлы прошивки. Исходный
   checkout требует отдельной сборки, описанной в `receiver/README.md`.
2. Подготовка определяет плату и сохраняет полный flash backup. Проверьте ESP
   и путь backup, подтвердите замену прошивки и нажмите «Установить прошивку».
   Это удалит прежнюю прошивку и настройки именно выбранной платы. Затем
   нажмите «Завершить установку» и «Прочитать настройки ESP».
3. Задайте физические GPIO (маркировка D2 не обязательно означает GPIO2),
   количество RGB-диодов каждого выхода, порядок цветов и подходящий питанию
   лимит тока. Для Wi-Fi введите сеть и пароль при USB-подключении. Сохраните.
4. На странице **«Ленты»** сохраните программные секции: начало с1, длина,
   направление. Секции не пересекаются; пропуски остаются чёрными. Проверьте
   направление и RGB краткими тусклыми тестами. «Остановить проверку» и общий
   выключатель прекращают тест; выключенную ленту сцена сама не включает.
5. Вернитесь в «Подключение», проверьте Wi-Fi и выберите **«Работать по Wi-Fi»**.
   После подтверждения можно отключить USB компьютера и запитать плату от
   подходящего отдельного USB-блока. Напряжение питания ленты должно совпадать
   с её номиналом, данные и питание должны иметь общую землю.

При потере свежей музыки ESP гасит ленты. ПК выключен — музыка не продолжает
играться на ESP из очереди. Старую работающую WLED-плату перепрошивать не нужно.

## Уже есть WESP или WLED

Для привязанной WESP выберите соответствующий путь в «Подключение» и прочитайте
настройки. GPIO/count/order/current можно сохранять по Wi-Fi; смена Wi-Fi-сети
и первая привязка требуют USB. Сохранение выходов оставляет свет выключенным.
Прошивка0.2.1 поддерживает обновление по кнопке **«Обновить прошивку по Wi-Fi»**:
сохраняет настройки, после проверки подтверждает новый слот и оставляет свет Off.

Для существующего WLED выберите **«У меня WLED»**, найдите нужный USB-порт и
подключите его. Выходы и общее число диодов должны быть правильно настроены
в самом WLED. Для WLED сохраняется отдельный кадровый USB-путь.

## Музыка и сигналы

Включите подсветку и «Музыку». Захватывается системный выход, без микрофона.
Чувствительность задаёт заполнение, затухание смягчает спад, зажигание — подъём,
порог тишины отсекает слабый шум. Палитра «Из обоев» использует локальную картинку
или стандартное слайдшоу KDE. «Спокойный свет» использует акцент KDE.
На странице «Сигналы» есть цвет/эффект/интенсивность и временная проверка.
Предпросмотр музыки в окне расчётный: реальная доставка и ограничения питания
проверяются на ленте. Физическую ручку громкости колонок программа не видит.

## Обновить, откатить, удалить

Выполните `manage.py install` из нового релизного архива и сохраните напечатанный
путь backup. Перезапустите окно WESP. Для виджета может потребоваться повторное
добавление или перезапуск Plasma; это не требуется отдельному окну.

```sh
/usr/bin/python3 manage.py rollback /путь/к/резервной/копии
/usr/bin/python3 manage.py uninstall
```

Это альтернативные действия. Откат возвращает файлы и состояния служб, удаление
сохраняет пользовательские настройки. Вручную изменённые управляемые файлы
не перезаписываются автоматически.
